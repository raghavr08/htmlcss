# JavaScript & AI Quiz

This file contains the quiz questions and expected answers.

> **Note:** Markdown (`.md`) files are documentation files and cannot execute JavaScript or display the interactive quiz. The interactive quiz logic belongs in `script.js`.

## Questions

### 1. What does a large language model actually predict?

- The next token — **Correct**
- The next webpage
- The next computer
- The next image

### 2. What comes before the colon in a commit message format?

- A paragraph
- A type such as feat/fix — **Correct**
- A password
- A URL

### 3. What must a unit test do before a bug is fixed?

- Pass
- Disappear
- Fail — **Correct**
- Restart the computer

### 4. Where should styling live?

- Inside the JavaScript file
- Inside the CSS file — **Correct**
- Inside the browser console
- Inside the URL

### 5. A nested loop usually means what?

- Constant time
- Quadratic time — **Correct**
- No computation
- HTML styling
